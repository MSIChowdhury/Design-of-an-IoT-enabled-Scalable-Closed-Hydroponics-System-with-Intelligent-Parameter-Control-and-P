# Data Availability Statement Draft

All data and code used for this study are available in the GitHub repository at https://github.com/MSIChowdhury/Design-of-an-IoT-enabled-Scalable-Closed-Hydroponics-System-with-Intelligent-Parameter-Control-and-P.

Timestamped actuator-command/state logs are not available for the historical deployment because those records were not retained; replay false-authorized-actuation results therefore remain replay quantities rather than measured physical disturbances.

For double-anonymized review, the blinded manuscript should refer to the repository disclosed in the submission metadata rather than printing the identifying URL.
