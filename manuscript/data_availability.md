# Data Availability Statement Draft

Code, configuration files, processed-data descriptors, paper-generation assets, and Docker workflow files will be supplied through the submission repository or an archival record. If an archive DOI is assigned before publication, cite it in the manuscript data statement and reference list.

Raw hydroponic files are not committed during review because they require credential removal and private operational-field review. The curated hydroponic sensor feed is planned for release or deposit after that review. Timestamped actuator-command/state logs are not available for the historical deployment because those records were not retained; replay false-authorized-actuation results therefore remain replay quantities rather than measured physical disturbances.

SWaT and WaDi raw data are not redistributed because they are request-access datasets from iTrust. Public third-party datasets can be obtained from their original providers, and restricted datasets must be obtained under the providers' terms.

For double-anonymized review, do not include identifying repository URLs in the blinded manuscript. Add repository and archive links in the submission metadata, title-page package, or final unblinded data statement according to ISA Transactions and Elsevier instructions.
