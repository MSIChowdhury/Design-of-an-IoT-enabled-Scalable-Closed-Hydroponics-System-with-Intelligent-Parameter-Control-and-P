# Data Availability Statement Draft

Code, configuration files, toy reproducibility data, processed-data descriptors, and scripts for reproducing the analysis are provided with the submission package.

Hydroponic data availability will be specified before submission after privacy, credential, and ownership review.

SWaT and WaDi raw data are not redistributed because they are request-access datasets from iTrust. Scripts and configuration files are provided so researchers can reproduce the analysis after obtaining access from the original provider.

Other third-party datasets are cited and used according to their original licenses and distribution terms.
