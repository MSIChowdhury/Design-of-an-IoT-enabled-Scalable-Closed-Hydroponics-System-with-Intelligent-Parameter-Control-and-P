# ISA Transactions Submission Checklist

- Separate title page prepared.
- Anonymized manuscript contains no author names, acknowledgements, or identifying repository links.
- Abstract is no more than 125 words.
- Highlights file has 3 to 5 bullets, each no more than 85 characters.
- Graphical abstract prepared if used.
- Data availability statement prepared.
- Declaration of competing interest completed.
- Declaration of generative AI use completed if applicable.
- Restricted third-party datasets are not redistributed.
- Tables are editable text.
- Equations are editable text.
- All figures and tables can be regenerated from scripts.
