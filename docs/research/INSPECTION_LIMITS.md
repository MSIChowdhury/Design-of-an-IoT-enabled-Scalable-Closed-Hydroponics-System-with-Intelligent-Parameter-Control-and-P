# Inspection limits and evidence needed next

The inventory, human coverage ledgers, raw-data profiles and binary metadata
describe different inspection depths. A hash or a successful parser is never
counted as reading a scientific argument. The two generic writing guides and
the Elsevier vendor class/template documentation are not research evidence;
their incomplete or excluded reading is recorded. No credentials were opened.
The public input copy in `data/Actual/` was compared locally and left untouched.

All 13 notebook source/markdown extracts were read. Their saved output types
were catalogued but models were not retrained. The original sensor-analysis
notebook still expects `feeds (2).csv` and has an empty cleaning step. The
XGBoost notebook generates threshold-rule labels on synthetic independent
features, omits the ninth action from its binary slice, uses an unrounded
regressor with an accuracy scorer in its grid search, and has no seeded Python
data generator. Its scores cannot supply independent control validation.
The MATLAB optimizer uses unavailable absolute Windows input/output paths and
an unbounded stopping loop; its error-count objective does not use the trusted
value it updates through beta. It was read, not launched as an expensive
optimization experiment. These historical paths are not the current paper's
evidence base and were preserved.

The metadata pass inspected 952 binary files: raster dimensions, PDF page
counts, all local SQLite table counts, and CAD/pickle identity. SQLite was opened
with `mode=ro`; no model pickle was deserialized and no CAD file was altered.
This is not a physical geometry review or an exhaustive correctness check of
every process journal. The complete current PDFs were rendered and visually
inspected, with final bibliography pages rechecked after citation corrections.
Other historical plots and large command traces are not asserted to have
received exhaustive visual or per-command adjudication. Ten larger historical
tables have schema/count/edge-row inspection only, precisely listed in the
reviewer ledger. Archived source copies receive full-read credit only when
their bytes equal already-read source; four different snapshots have diff-only
status. Synthetic stand-in, injected faults, replayed traffic and mock actuator
effects remain separately labelled throughout.

The minimum stronger hydroponic experiment needs a calibrated independent
pH/EC reference, a retained timestamped command log, and observed relay/current
or delivered-volume evidence in an independent benchtop run. Freeze the
candidate, simple range/persistence comparator, known faults and legitimate
steps before collection. Randomize complete independent sessions, preserve
initial conditions/mixing history, and analyze both wrong delivered actions
and missed correct opportunities. Use a small pilot to estimate session-level
variability, then freeze a precision-based confirmatory sample size on new
sessions. The current flag frequencies cannot legitimately substitute for a
baseline *wrong-dose* frequency. A final sample size or acceptance threshold
cannot be justified from nonexistent reference truth.

Required resources are reference calibration, an instrumented/supervised dosing
setup, independent run time, and authorization for collection or expense if
needed. None was procured or run. For a stronger recovery paper, an independently
clocked physical/instrumented effect interface and an equally informed durable
baseline are additionally needed; another cyclic same-host trace is insufficient.
No causal crop experiment is justified without independently replicated systems
or randomized complete production runs with the other treatment factors controlled.
