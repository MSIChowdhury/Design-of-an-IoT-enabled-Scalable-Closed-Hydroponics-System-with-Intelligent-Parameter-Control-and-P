# Results

Generated files are written here by the reproducible scripts:

- `results/metrics/`
- `results/tables/`
- `results/figures/`
- `results/run_metadata/`

Small toy-run outputs are acceptable for smoke testing. Large benchmark outputs should be regenerated locally and reviewed before committing.

Cross-dataset manuscript tables are generated when prepared datasets exist:

- `results/tables/dataset_summary.csv`
- `results/tables/main_benchmark_table.csv`
- `results/figures/cross_dataset_rank_plot.png`
